# 미사용 아이콘 신규 스킬

401~413은 4번 동료의 사냥꾼 계열, 501~513은 5번 동료의 암술사 계열이다. 총 26개를 기존 카탈로그에 추가했다.
생성 전 해당 아이콘의 GUID를 참조하는 씬·프리팹·에셋이 없음을 확인했다. 아이콘 이미지를 바탕으로 새로 설계했으며 원본 스킬 프리팹은 없다.

쿨타임은 사용한 라운드 이후 재사용할 수 없는 라운드 수다. 0은 다음 라운드부터 사용 가능하다. 상태 효과는 저항 판정을 받으며, 전체 효과도 대상 열 제한을 따른다.
ForgeOptions에는 실제 효과에 맞는 강화만 포함했다. 쿨타임 강화는 기존 정책대로 동료 최대 체력 +5이다.
