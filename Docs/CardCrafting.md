# 카드 분해와 조합

대장간(ForgeScene)의 분해 탭에서 보유 카드를 선택하고 획득 재료와 각 마나값을 확인한 뒤 분해한다. 카드는 덱에서 제거되고 단어·문장은 UserData.cardPhrases에 보관된다. 덱의 마지막 1장은 분해할 수 없다.

조합 탭에서 재료를 2개 이상 선택한다. 선택한 순서와 마나 합계를 미리 확인할 수 있으며 다시 클릭하면 선택이 해제된다. 조합하면 선택한 재료가 소모되고 새 카드가 덱에 추가된다. 효과 없는 단어와 소멸만으로는 카드를 만들 수 없다. 탭 전환은 선택만 초기화하며 보유 재료는 유지된다.

- CardPhrase: 효과 종류, 수치, ManaCost, 전체 대상 여부, 단어를 보관한다. 모든 기본 효과의 마나 비용은 5 이상이며 새 재료의 기본 비용은 5다.
- Card.GetPhrases(): 기존 카드의 분해 규칙과 문장별 비용을 지정한다. 기존 카드 비용과 효과를 보존한다. 공격·스킬 분류 키워드는 생성하지 않는다. 단일 효과 카드는 효과 문장 1개를 재료로 얻으며 다른 카드에서 얻은 재료와 조합할 수 있다.
- Card.Cost: 항상 구성 문장의 ManaCost 합계다. 조합 카드의 문장은 Phrases에 저장되며 전투 시작 시 깊은 복사된다.
- 효과는 선택 순서대로 발동한다. 단일 대상 문장과 전체 공격을 함께 사용해도 각 문장의 대상 범위가 유지된다.
- 대장간 강화는 방문당 1회이며 조합 카드에도 적용된다. 분해·조합은 반복 이용할 수 있다. 재료는 원정 동안 유지되며 새 원정에서 초기화된다.
- 화면은 Assets/Prefabs/Forge/CardWorkshop.prefab에 저장되어 ForgeScene에서 참조한다. 재작성 메뉴는 FailingQuest/Build card workshop이다.

검증: Unity 컴파일, CardCombatChecks.Run(), CardCraftingChecks.Run() 통과. 모든 기본/강화 카드 22종의 분해·조합 왕복, 재료 소모, 전투 복사, 마나 합산, 복합 대상과 효과 순서, 잘못된 선택의 무변경, JSON 왕복을 확인했다. Play Mode에서 대장간 분해·선택·미리보기·조합·페이지 이동·조합 카드 강화·방문당 강화 제한을 확인하고 화면을 육안 검토했다.

## 100 마나 비용 조정

최대/기본 시작 마나는 100이며 회복은 최대치를 넘지 않는다. 턴 시작 시 마나는 자동 회복되지 않는다.

| 카드 | 비용 |
| --- | ---: |
| 타격 | 10 |
| 수비 | 10 |
| 균열 | 15 |
| 분쇄 | 20 |
| 철벽 반격 | 15 |
| 집중 | 10 |
| 불굴 | 15 |
| 회오리 | 20 |
| 속공 | 10 |
| 전투 태세 | 15 |
| 마나 샘 | 5 |

강화 후에도 비용은 동일하다. 취약·보조 방어·1장 뽑기·소멸은 각각 5 마나이며 모든 카드 비용은 문장 비용 합계다. 마나 샘은 5를 먼저 소모한 뒤 30(강화 50)을 회복하므로 마나가 5 미만이면 사용할 수 없다.
