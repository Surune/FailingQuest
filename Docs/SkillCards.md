# 스킬 → 카드 데이터

기존 SkillCatalog에 등록되어 있던 스킬 66개를 `Assets/ScriptableObjects/Cards/Card_XXX.asset`으로 변환했다. 001 이동은 변환 당시 카탈로그에 없었으므로 포함되지 않는다.

`CardDefinition`에서 원본 ID, 이름, 아이콘, 효과 문장과 각 문장의 마나 비용을 편집한다. `CardCatalog.asset`이 전체 카드를 참조하고 GameServices와 CardBattle 프리팹이 이 카탈로그를 직접 참조한다. 전투 보상, 카드 획득 노드, 상점/이벤트의 무작위 획득은 기존 카드 9종과 변환 카드 66종을 사용한다. 기본 덱은 유지한다.

원본 ID가 기존 기본 카드 ID와 겹칠 수 있으므로 런타임 Card의 Defined로 구분한다. 생성할 때 문장을 복사하고 이름과 아이콘을 유지한다. 원본 에셋은 전투/강화/분해로 변경되지 않는다. 변환 카드도 강화, 분해, 조합할 수 있다.

## 카드 규칙 변환

- 피해와 회복 범위는 정수 평균으로 고정한다. 아군 대상은 플레이어로 통합한다.
- 출혈/중독/화상은 위력×지속시간의 즉시 피해로 변환한다. 자기 피해와 양 진영 피해의 플레이어 페널티도 포함한다.
- 보호는 방어도, 공격력 증가/집중은 힘 증가, 적 공격력 감소/기절은 전투 동안 적 공격력 감소로 변환한다. 자기 감소/기절은 힘 감소로 변환한다.
- 표식은 취약으로, 스트레스는 아군 드로우 1 또는 적 취약 1로 변환한다. 효과 없는 이동은 드로우 1이다.
- 상태의 진형 전투 지속 시간은 제거되며 방어도/힘/취약 등 카드 전투 규칙을 따른다. 지속 피해 합계와 표식의 취약 턴 수 계산에는 원본 지속 시간을 사용한다.
- 문장당 기본 마나 5, 첫 문장에 원본 쿨타임×5를 더한다. 원본 쿨타임은 카드에서 재사용 대기시간으로 작동하지 않는다.
- 강화 시 피해/방어/회복 +3, 긍정적인 힘/드로우/취약/공격력 감소 +1. 자기 페널티는 강화되지 않는다.

각 카드의 ConversionNotes에 원본 설명과 변환 기준을 저장했다. 이 변환은 기존 카드 규칙으로의 재설계이며 원본 진형 전투 효과와 동일하지 않다. 전체 원정 밸런스 플레이 검증은 수행하지 않았다.

## 도구와 검증

원본 CombatSkills 폴더와 전용 정의/카탈로그 클래스, 일회성 변환 도구, 원본 스킬 검증 도구를 제거했다. 카드 데이터는 Cards 폴더에서 직접 편집한다. GameServices와 기존 RankBattle의 스킬 카탈로그 참조도 제거했다. 기존 진형 전투는 프리팹에 내장된 기본 스킬을 사용하고, 획득 스킬을 네 번째 슬롯에 장착하는 경로는 제거했다. 아이콘은 기존 AbilityIcons 배열을 사용한다.

Unity 컴파일 및 `CardDataChecks.Run()` 통과: 66개 ID 대응, 일반/강화 132가지 전투 사용, 깊은 복사, 분해 문장/비용 보존, 회복 상한, 적 공격력 감소. 기존 CardCombatChecks와 CardCraftingChecks도 통과했다.

상점은 입장 시 카드 상품을 정하고 이름·마나 비용을 표시한다. 50골드 구매 시 표시된 카드의 복사본을 지급하며 재구매는 차단한다. ShopScene의 3개 카드 판매 슬롯과 CardBattle 프리팹의 승리 보상 선택을 에디터에서 실행하여 변환 카드 등장과 지급을 검증했다.
