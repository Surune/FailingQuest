# 진형 전투

`Assets/01_Scenes/BattleScene.unity`는 `Assets/02_Prefabs/Battle/RankBattle.prefab`을 사용한다.
기존 씬 구성은 `Legacy Battle (preserved)` 아래 비활성 상태로 보존했다.
런타임에 UI나 전투 오브젝트를 생성하지 않으며, 프리팹에 저장된 참조를 사용한다.

## 플레이

- 시작 화면 → 캐릭터 선택 → 지도 → 일반 전투의 기존 진입 경로를 사용한다.
- BattleScene을 직접 실행해도 기본 4인 파티로 테스트할 수 있다. 이 경우 결과 화면에서 시작 화면으로 돌아간다.
- 기존에 선택한 3인은 유지하며, 빠진 역할의 지원대원을 추가해 4인으로 출전한다.
- 스킬 버튼 또는 숫자 1~4로 스킬을 선택하고, 표시된 아군/적을 클릭한다.
- Q / E: 전진 / 후퇴. Space: 대기(스트레스 +5). ESC: 선택 취소 / 도움말 닫기.
- 우측 상단 전투 안내에서 규칙을 확인할 수 있다. 전투 이탈은 75% 확률이며 실패하면 행동을 소모한다.

## 전투 규칙

- 양 진영 최대 4열. 상대에게 가까운 자리가 1열이다.
- 라운드마다 속도 + 1~8로 행동 순서를 정한다. 생존자는 라운드마다 한 번 행동한다.
- 스킬별 사용 열, 대상 열, 아군/적 대상과 광역 범위를 별도로 지정한다.
- 명중, 회피, 치명타, 보호, 상태이상 저항을 판정한다.
- 출혈·중독은 대상의 행동 시작 시 피해를 주고, 기절은 행동을 소모한다. 기절 후에는 일시적으로 기절 저항이 증가한다.
- 직접 피해로 죽은 적은 시체로 자리를 막는다. 시체를 공격하면 제거된다. 지속 피해로 죽으면 시체를 남기지 않는다.
- 영웅은 HP 0에서 죽음의 문턱에 들어간다. 이후 피해마다 67% 확률로 죽음의 일격을 저항하며, 치유하면 문턱에서 벗어난다.
- 스트레스 100에서 25% 각성 / 75% 붕괴를 판정한다. 붕괴는 속도·피해 감소와 행동 포기, 각성은 피해 증가와 확률적 스트레스 회복을 제공한다.
- 스트레스 200에서 붕괴한 영웅은 심장마비를 겪는다. 죽음의 문턱에서 심장마비가 발생하면 사망한다.
- 적 전멸: 승리 및 100 골드. 아군 전멸: 패배. 결과 버튼은 지도 또는 게임오버로 연결된다.

## 의도한 범위

다키스트 던전 1편의 진형·턴·상태·스트레스 전투 구조를 이 프로젝트에 맞춰 구현했다.
원작의 에셋, 직업 전체, 개별 스킬 수치, 모든 정신 상태 및 저항 종류를 그대로 복제한 것은 아니다.
현재는 수호자·추적자·연금술사·치유사와 고정 4종 적의 한 전투 구성을 제공한다.
스킬은 역할별 새 4개 세트를 사용한다. 기존 CSV 스킬 선택 및 대장간 강화는 새 스킬 세트에 적용되지 않는다.
체력·스트레스는 전투 내 상태이며, 다음 전투까지 이어지는 원정 상태 저장/부활/영구 사망은 구현 범위에 포함하지 않았다.
기존 지도 생성·퀘스트 진행·저장 방식은 변경하지 않았다.

## 편집 및 검증

- 프리팹의 RankBattleController에서 Heroes / Enemies 템플릿, 스킬 범위·수치·스프라이트를 수정한다.
- CombatModel은 씬과 독립적인 순수 전투 상태이며, RankBattleController가 UI와 애니메이션을 연결한다.
- `FailingQuest/Author rank combat prefab` 메뉴는 기본값으로 프리팹을 재생성한다. 수동 프리팹 편집을 덮어쓰므로 편집 내용을 유지하려면 실행하지 않는다.
- 생성기는 Editor 전용이다. 기존 씬 오브젝트는 보존하고 자신이 생성한 프리팹 인스턴스만 교체한다.
- 에디터에서 `RankCombatChecks.Run()`을 실행하면 턴·대상·이동·시체·지속 피해·기절·스트레스·승패·후퇴 회귀 검사와 시드 10개의 완전한 전투를 검사한다.
- 직접 플레이에서는 스킬 버튼→대상 버튼, 중복 클릭 차단, 적 AI 자동 행동 및 결과 패널을 점검했다. 실제 UI 버튼으로 23회 행동하여 7라운드 뒤 승리 패널까지 도달했으며 런타임 오류는 0건이었다.
