# 게임 흐름 구현 및 검증

## 현재 동작

- 시작 → 캐릭터 1명 선택 → 첫 퀘스트 → 지도 → 각 노드 → 지도 복귀.
- 전투에는 플레이어 1명과 적 최대 5명이 참가한다. 위치에 따른 사용·대상 제한, 이동, 시체 차단은 없다.
- 플레이 중 데이터는 GameManager의 userData와 currentMap에만 유지한다. 지도와 방문 경로는 같은 메모리 객체를 장면 사이에서 공유한다.
- 저장·불러오기, 자동 저장, 체크포인트와 이어하기 기능은 없다. 종료 후 다시 실행하면 새 게임으로 시작한다.
- 새 게임은 캐릭터·보유 자원·퀘스트·지도를 초기화한다. 클리어와 전멸은 지도를 비우고 현재 원정의 결과를 표시한다.
- 일반·엘리트·보스 전투의 보상은 각각 100·150·250골드다. 전투 종류는 현재 지도의 방문 경로에서 판정한다.
- 전투 후퇴 시 마지막 방문 경로를 취소하고 지도로 돌아간다.
- 원정 결과 화면은 다시 도전/홈 버튼을 제공한다. 다시 도전은 새로운 원정을 시작한다.

## 검증

- Unity 스크립트 컴파일 오류 없음. 모든 씬의 스크립트 참조 검사 통과.
- FlowValidation/FlowChecks.cs: 캐릭터 선택, 첫 퀘스트, 지도·자원의 메모리 유지, 일반/엘리트/보스 전투와 보상, 중복 보상 방지, 클리어, 재도전, 후퇴, 전멸 등 24개 검사 통과.
- 시작 메뉴에 이어하기 버튼이 없으며, 플레이 모드 종료·재실행 후 이전 골드와 경로가 복원되지 않는 것을 확인했다.
- 런타임 코드에 PlayerPrefs, DataManager, 체크포인트 또는 지도 저장 호출이 남아 있지 않다.
- 흐름 검사의 승리/전멸은 결과 분기를 확인하기 위해 전투 상태를 지정한다. 전투 밸런스 검증은 별도다.
