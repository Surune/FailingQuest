# 진형 전투 스킬 정의

`Assets/ScriptableObjects/CombatSkills`에 총 67개 스킬 정의가 있다.
001~313의 41개는 기존 스킬 프리팹에서 변환했다. 변환 완료 후 원본 폴더와 Skeleton, 기존 씬의 스킬 인스턴스 및 로드 코드를 제거했다.
401~413과 501~513의 26개는 미사용 아이콘에서 창작한 스킬이다. [신규 스킬 목록](NewCombatSkills.md)을 참고한다.
`SkillCatalog.asset`에 전체 정의가 들어 있고 GameServices와 RankBattle 프리팹이 직접 참조한다.

## 편집

각 `CombatSkillDefinition`의 `Skill`에서 사용 열(`From`), 대상 열(`To`), 효과, 수치, 지속 시간, 쿨타임을 편집한다.
`AdditionalEffects`는 주 효과 이후 적용할 효과와 대상을 정의한다. `Selected`는 주 효과가 명중한 살아 있는 대상,
`Self`는 시전자 한 명, `Allies`/`Enemies`는 각 진영 전체다. 전체 공격의 자기 페널티는 한 번만 적용한다.
주 효과의 `SelfOnly`는 자신, `BothTeams`는 양 진영, `All`은 선택 가능한 대상 전체를 뜻한다.
`Description`은 표시용 문구이므로 수치를 편집할 때 함께 갱신한다. 전투 동작을 설명 문자열에서 추론하지 않는다.
`Icon`은 스킬 아이콘이다. 원본 프리팹 참조는 제거했고, 변환 기록은 `ConversionNotes`에 남아 있다.

정의는 전투에 투입할 때 깊은 복사하므로 강화와 전투 중 상태 변화가 원본 에셋을 바꾸지 않는다.
보상 후보, 보상 설명, 대장간 이름·아이콘·강화 선택지는 동일 카탈로그를 사용한다.
기존 보유 ID와 저장 형식, 마지막 획득 스킬을 네 번째 슬롯에 장착하는 규칙은 유지했다.
진형 전투에 원래 있던 기본/적 스킬은 이번 원본 프리팹 변환 대상에 포함되지 않는다.

## 변환 기준

- 모든 스킬은 한 번의 행동을 소모한다.
- 원본 쿨타임 1~30 / 31~60 / 61~90 / 91~120은 사용 후 0 / 1 / 2 / 3개 라운드 동안 재사용 불가로 변환했다.
  예: 1라운드에 쿨타임 1 스킬을 쓰면 2라운드는 사용할 수 없고 3라운드부터 가능하다.
- 단일 공격·회복은 원본 수치의 2배~2배+2, 전체 공격·회복은 원본 수치~수치+2다.
- 화상은 중독과 별개의 지속 피해로 유지한다. 공격력 증감은 고정 피해 증감, 속도 증감은 기존 수치/10 올림(최대 5),
  보호는 보호도 +25%, 집중은 명중 +10이다. 일반 상태는 3턴, 기절은 1턴이다.
- 강화 전 상태 효과의 피해량은 0이다. 공격 강화나 유물이 상태 전용 스킬에 피해를 추가하지 않는다.
- 공격 후 대상에게 적용하는 상태는 공격 명중을 공유하고 별도로 상태 저항을 판정한다.
  자신/다른 진영 대상의 부가 효과는 따로 처리한다.
- 근접 스킬 002/108/204/207/211은 1~3열에서 적 1~2열을 대상으로 한다.
  나머지 적 대상 스킬은 2xx 계열은 1~3열, 1xx/3xx 계열은 2~4열에서 사용한다.
  자기/아군 지원과 양 진영 전체 효과는 모든 열에서 사용한다.
- 001/209는 한 칸 전진, 113은 한 칸 후퇴로 변환했다. 적 진영의 위치는 변경하지 않는다.
- 대장간의 기존 캐릭터 단위 강화와 쿨타임 강화의 속도 +1 정책은 유지했다.
  실제 효과에 맞춰 강화 후보를 생성하며 복합 효과의 버프/디버프도 강화한다.

상세 변환 기록은 각 에셋의 `ConversionNotes`에도 저장했다.

## 편집과 검증

일회성 프리팹 변환 도구는 제거했다. 스킬 에셋을 직접 편집하며, 신규 스킬은 `Create/FailingQuest/Combat/Skill`로 만들고 `SkillCatalog.asset`의 Skills 배열에 등록한다.
`FailingQuest/Skills/Validate combat skills`는 전체 스킬의 참조·대상·실행·복사 독립성,
복합 효과·이동·쿨타임·상태 지속 시간·획득 및 강화 연결과 10개 시드 전투 검증을 실행한다.
