# 카드 전투

## 실행

- 전체 원정: `Assets/Scenes/StartScene.unity`에서 Play.
- 전투만 체험: `Assets/Scenes/BattleScene.unity`에서 Play. 마나 샘 2장을 포함한 기본 덱 12장으로 시작.
- 화면 프리팹: `Assets/Prefabs/Battle/CardBattle.prefab`. 런타임 UI 부트스트랩 없이 저장된 오브젝트와 레퍼런스를 사용한다.
- 재생성: Unity 메뉴 `FailingQuest/Build card battle`. 보상 노드 레이아웃은 `FailingQuest/Format card reward nodes`.

## 규칙

전투마다 마나 100으로 시작한다. 마나는 턴이 바뀌어도 회복되거나 초기화되지 않는다. 매 턴 드로우 5장, 손패 최대 10장. 공격 카드 클릭 후 적을 클릭한다. 스킬과 전체 공격은 즉시 사용된다. 숫자 1–9로 카드 선택, Space로 턴 종료, ESC로 선택 취소, D로 덱 확인.

턴 종료 시 남은 손패를 버리고 살아 있는 적이 예고한 행동을 순서대로 실행한다. 방어도는 다음 내 턴 시작에 사라진다. 뽑기 더미가 비면 버린 카드를 섞는다. 소멸 카드는 해당 전투에서 제외된다. 취약은 받는 공격 피해를 50% 늘리며 적 행동 후 1턴 감소한다.

카드 11종: 타격, 수비, 균열, 분쇄, 철벽 반격, 집중, 불굴, 회오리, 속공, 전투 태세, 마나 샘. 각 카드는 영구 강화 가능하다. 동일 카드도 별도의 덱 항목으로 유지된다.

일반 전투는 적 2명, 정예는 3명, 보스는 생명력 150의 적 1명이다. 승리 시 골드와 3장 중 1장 카드 선택 보상을 받는다. 카드 보상은 건너뛸 수 있다. 지도·이벤트·상점의 카드 획득과 강화도 같은 덱에 적용된다. 유물의 공격력과 최대 생명력 보너스가 전투에 적용된다. 모든 유물의 공격 피해 보너스는 카드 전투에도 적용한다.

진행 상태는 기존 GameManager의 원정 수명 동안 유지되며 재도전 시 초기화된다. 앱 종료 후 이어하기는 구현하지 않았다. 캐릭터 선택은 기존 초상화를 사용하며 현재 모든 캐릭터가 같은 기본 카드 덱과 체력을 사용한다.

## 검증 (2026-09-14)

- Unity 6000.3.15f1 컴파일 성공.
- `CardCombatChecks.Run()` 통과: 드로우·마나, 부족한 마나로 사용 차단, 피해와 방어, 턴 초기화, 취약, 버림 재섞기, 드로우 카드 자기 재드로우 방지, 소멸, 손패 제한, 전체 공격, 승리·패배, 덱 복제 격리, 20턴 카드 수 보존.
- Play Mode: 버튼으로 턴 종료 → 적 행동 → 마나 10 소비 후 두 번째 턴에도 마나 90/손패 5장 유지 확인.
- 캠페인: 전투 승리 → 카드 보상 한 장만 추가 → 골드 지급 → MapScene 복귀와 덱 유지 확인.
- SkillScene 카드 획득, ForgeScene 카드 강화, ShopScene 50골드 카드 구매 및 중복 구매 차단 확인.
- 보스 승리 → GameClearScene, 패배 → GameOverScene 전환 확인.
- 승패 경계 검증은 런타임 테스트 상태에서 공격력 또는 체력을 조정해 실행했다. 전체 원정의 난이도 밸런스 검증을 의미하지 않는다.
- 전투·보상·강화 화면 캡처를 확인하고 강화 텍스트 겹침 및 적 초상화 위치 수정.
- 수정 후 Play Mode 콘솔에 새로운 오류 없음. 기존 콘솔 기록은 삭제하지 않았다.

핵심 규칙은 `CardCombatModel`, 프리팹 UI와 원정 연결은 `CardBattleController`에서 관리한다. 기존 RankCombat 코드는 보존되어 있지만 BattleScene의 활성 전투는 CardBattle 프리팹이다.

## 전투 마나 변경

시작 마나는 CardBattle 프리팹의 StartingMana(기본 100)로 조절한다. 최대 마나는 100이며 시작량과 회복 결과는 이 상한을 넘지 않는다. 현재 마나는 다음 턴에도 유지된다. 새 전투에서는 다시 StartingMana로 시작한다.

마나 샘: 비용 0, 마나 30 회복(강화 시 50), 사용 후 버림 더미로 이동하며 재섞기 후 다시 뽑을 수 있다. 기본 덱에 2장 포함하고 전투 보상, 카드 획득 노드, 상점 무작위 카드 풀에도 포함한다.

추가 규칙 검증: 소비한 마나/마나 0/회복한 마나/최대 마나의 턴 간 유지, 새 전투 시작량, 설정된 시작량, 일반·강화 회복, 모든 카드 설명 접근, 기본 덱 회복 카드 2장 포함.

카드 비용은 기존 대비 10배로 조정했다. 타격·수비·균열·철벽 반격·불굴·전투 태세는 10, 분쇄·회오리는 20, 집중·속공·마나 샘은 0이다. 조합 비용은 조정된 문장 비용의 합이다.
