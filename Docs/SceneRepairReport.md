# 씬 수정 및 검증 기록

## 수정 범위

- 13개 씬의 진입과 주요 연결을 점검했다. 전투 씬의 기존 배치 및 기존 작업 파일은 보존했다.
- 전투 이외 씬에 GameServices 프리팹을 배치했다. 데이터 매니저 중복 생성 시 기존 인스턴스를 파괴하던 오류와 시작 화면의 데이터 매니저 누락을 수정했다.
- 공통 Quest 프리팹의 Missing Script를 복구하고 상점의 고아 스크립트를 제거했다.
- 보물 획득의 빈 리스트 인덱스 예외, 중복 보물 재추첨의 무한 반복, 카메라·툴팁·프리팹 참조를 수정했다. 보물은 인덱스로 저장하고 UI는 저장된 인벤토리에서 재구성한다.
- 대장간의 잘못된 101번 스킬 인덱스, 후보 수 부족, 강화 전에 씬을 떠나는 버튼 순서를 수정했다. 후보가 없을 때에도 복귀 버튼이 표시된다.
- 스킬 씬에 실제 선택 동작을 추가하고 빌드 목록에 등록했다.
- 이벤트 선택에 효과와 이동을 연결했다. 엘리트·보스·스킬 노드의 이동을 연결했다.
- 맵 재진입 시 경로/배치를 유지하고 완료한 노드 다음으로 이동할 수 있다. 보스 승리는 클리어 화면, 후퇴는 직전 노드를 다시 선택할 수 있도록 처리한다.
- 퀘스트 완료 조건, 완료 보상, 슬롯 교체 및 진행도 초기화를 연결했다.
- 시작 화면의 잘못된 빈 씬 이름 호출을 제거하고 도움말/크레딧 패널을 연결했다. 구현되지 않은 여섯 번째 캐릭터 버튼은 숨겼다.
- 대장간/스킬 카드와 복귀 버튼을 1280×720 기준의 화면 비율 대응 배치로 수정했다.

## 승인받아 추가한 게임 규칙

- 상점: 스킬 50코인, 유물 90코인, 파티 체력 30% 회복 30코인. 표시 가격은 실제 가격과 동기화한다. 각 상품은 방문당 한 번 구매할 수 있다.
- 이벤트: 30코인 획득, 30코인으로 보물 구입, 체력 20%를 바치고 50코인 획득, 습득 스킬 하나를 삭제하고 50코인 획득, 파티 체력 30% 회복. 구매/획득 가능한 항목만 활성화한다.
- 유물: 금화는 즉시 50코인, 빨간 책은 공격 피해 +1, 파란 책은 최대 체력 +5, 초록 책은 속도 +1. 4종 모두 수집하면 상자를 생략하고 복귀할 수 있다.
- 전투 종료 체력은 다음 전투에 유지한다. 승리/후퇴 후에는 최소 체력 10%로 회복해 재출전한다. 전멸은 게임 오버로 이동한다.
- 기존 CSV 스킬과 새 턴제 전투 스킬 체계가 달라 호환 규칙을 추가했다. 마지막 획득 스킬이 해당 캐릭터의 4번 슬롯을 대체한다. 회복은 4~8 회복, 화상은 피해 4~8 및 중독 2, 감소 효과는 표식, 증가 효과는 보호, 나머지는 피해 4~8로 변환한다. 화면에 실제 적용 효과를 표시한다. 원본 CSV의 복합 효과 전체를 재현하는 방식은 아니다.
- 강화는 해당 스킬 보유 동료에게 적용된다. 기존 쿨타임 강화는 턴제 속도 +1, 피해/회복은 +1, 버프/디버프는 강도 및 지속 시간 +1이다.
- 퀘스트 완료 보상은 난이도에 따라 25/50/75코인이다. 기존 화상/집중/방어 조건은 새 전투 체계의 중독/표식/보호 부여로 대응한다.
- 새 게임 선택 시 파티, 체력, 인벤토리, 퀘스트, 지도 진행을 초기화한다.

## 검증

Unity 6000.3.15f1 에디터에서 실시했다.

- 13개 씬을 플레이 모드 실제 프레임 진행으로 순회: 진입 예외 없음, GameManager/DataManager 각각 1개 유지.
- 상호작용 검사: 도움말/크레딧, 파티 선택/취소, 스킬 획득, 강화, 후보 소진, 상점 3종, 유물 중복 방지/전부 수집, 퀘스트 교체, 이벤트 복귀, 전투 초기화, 저장 왕복.
- 경로 검사: 지도 배치/방문 경로 유지, 다음 노드 해제, 보스 승리 후 GameClearScene 이동 및 지도 저장 삭제.
- 기존 RankCombatChecks 및 시드 100개 자동 전투 통과.
- 검증 스크립트는 이 문서 옆 SceneValidation에 보관했다. 플레이 모드 StartScene에서 각 Main을 실행하면 코루틴으로 검사하고 Temp/SceneAudit에 결과를 기록한다. 테스트는 현재 플레이 데이터를 변경하므로 실제 저장 데이터를 먼저 백업해야 한다.
- 테스트 시작 전 UserData/Map PlayerPrefs를 별도로 백업했으며 작업 종료 시 복원했다.
- 개발 빌드/배포 실행 및 모든 무작위 이벤트 조합의 수동 플레이까지 검증한 것은 아니다.
